# Changelog

Todos los cambios notables en ProCamera serán documentados en este archivo.

## [2.0.0] - 2024-09-09

### Añadido
- 🎨 Nuevo UI con efecto Glassmorphism
- 📱 Soporte para IP Webcam (Android)
- 📸 Captura de fotos individual y masiva
- 🎬 Grabación de video en tiempo real
- 📁 Explorador de archivos estilo VSCode
- 🖼️ Visor de imágenes con zoom
- ⚙️ Configuración completa de formatos y calidad
- 🌙 Modo oscuro por defecto

### Mejorado
- 🔄 Optimización del stream de video
- 📊 Mejor gestión de recursos
- 🎯 UI más intuitiva y responsive

### Corregido
- 🐛 Error de conexión con cámaras IP
- 🐛 Problemas de memoria en grabación larga

## [1.0.0] - 2024-08-15

### Añadido
- 🚀 Lanzamiento inicial
- 📷 Conexión básica con cámaras IP
- 💾 Guardado de capturas
